말투 · 응답 선호

사용자가 입력한 최대 500자 프로필을 판단 단계에 넣습니다. 예: “한국어 존댓말로 한 문장만 답해줘.” 모델을 다시 학습하는 방식은 아닙니다.

현재와 과거를 분리

완료된 대화 최대 8개, 과거 프레임 최대 4개를 세션에 보관합니다. 요청에는 최근 완료 대화 4개와 과거 프레임 최대 2개를 넣습니다. 현재 프레임은 수신 후 3초 이내만 인정합니다.

기억을 끝내는 방법

실제 Live 화면의 기억 지우기 또는 연결 종료로 프로필·대화·프레임을 폐기합니다. 이 문서의 ‘장면 기억’은 동작 원리를 보여 주는 고정 예시입니다.

개발 관점으로 펼쳐 보기: 입력, 스트리밍, 취소

수신은 추론을 기다리지 않음

16kHz mono PCM을 20ms 단위로 전송하고 카메라 JPEG를 1fps로 받습니다. RMS 임계값 0.018을 3청크 연속 넘으면 발화 시작으로 보고, 600ms 무음 뒤 발화를 종료합니다. 최대 발화 길이는 15초입니다.

두 종류의 스트리밍

ASR는 발화 종료 뒤 동작합니다. VLM은 문장 단위 텍스트를 보냅니다. 로컬 TTS 어댑터는 8 codec frame마다 약 640ms 길이의 24kHz 오디오를 복원합니다. 청크 길이가 실제 생성 속도를 뜻하지는 않습니다.

취소는 여러 겹으로 처리

브라우저 재생 큐를 비우고 서버 응답 번호(epoch)를 올립니다. LLM·TTS는 취소 신호로 생성을 멈춥니다. 진행 중인 ASR 계산은 끝날 수 있으나, 이전 번호의 결과는 전송하지 않습니다.
