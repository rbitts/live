# Android 실기기 임시 설치 — 2026-10-13

**판정: 사용자 지정 실기기에 앱·모델 설치, 실제 ASR → VLM → TTS 및 출력 중 마이크 입력 확인 통과.** 고정 입력을 사용하는 단일 smoke이며 사람의 Live 대화 합격은 아니다.

## 대상과 설치 상태

- 연결된 Galaxy Tab S10 Ultra 5G, SM-X926N, Android 16/API 36, ARM64. RAM 표시 약 16GB, 설치 전 여유 저장 공간 약 907GB.
- `0.3-icon-live-preview`, 앱 ID `dev.live.offline`. UI 상단 이름을 제거한 버전이며 이번 수정은 debug 검증 도구 옵션에 한정했다.
- 고정 모델 ZIP 약 5.5GB를 USB로 전송하고 앱의 ZIP 검증/설치 경로로 설치했다. 모델/MNN revision은 기존 [통합 기록](android-live-validation.md)을 유지한다. GPU나 클라우드는 사용하지 않았다. 앱은 INTERNET 권한이 없지만 이번 기기 전체를 비행기 모드로 바꾸지는 않았다.
- 카메라·마이크 권한을 허용했다. 마지막에는 센서 캡처를 시작하지 않은 라이브 대기 화면을 열었다. 사용자가 큰 마이크 아이콘을 눌러 시작할 수 있다.
- 설치용 중복 ZIP과 고정 질문/이미지는 검사 후 삭제했다. 설치된 모델은 앱 내부에 유지된다. 잠금 시험 중 임시로 늘린 화면 꺼짐 시간을 기존 300초로 복원했다. 공용 에뮬레이터 및 다른 앱/자동화는 종료하지 않았다.

한국어 TTS PCM callback을 확인했다. 질문 WAV와 GQA 이미지를 사용했고, 주변 마이크 신호로 질문 정확도를 평가하거나 실제 카메라 장면을 모델에 넣은 검사는 아니다. 첫 PCM 시간은 앱 제출→PCM callback으로 실제 스피커 첫 소리 측정이 아니다. 모델 준비 대기 8.208/8.807초도 전체 cold load와 구분한다.

## 발견한 실행 조건

첫 시도는 이미 연결된 UiAutomation 서비스와 스크린샷 수집이 충돌했다. 다른 서비스를 종료하지 않고 debug instrumentation에 `skipScreenshots` 옵션을 추가했다. 이후 잠금 화면에서 세션 중지로 응답 검사가 실패했다. 잠금 화면을 정상 해제한 뒤 동일 모델 경로가 통과했다. 마이크 비활성 고정 입력만 검증하는 `fixtureOnly`와 실제 환경을 표시하는 `scope` 옵션도 추가했으며, 비활성 시험을 마이크 동시성 합격으로 표시하지 않는다.

## 증거와 한계

로컬 증거는 `.runtime/android-device/`에 있다: `live-model-report.json`, `fixture-model-report.json`, `workflow-model.log`, 초기 실패 로그, `build-arm64.log`, `signature.log`, `zipalign.log`, 메모리 표본, 최종 화면, `verification-manifest.json`. 설치 APK는 `gyut-live-arm64-device-debug.apk`다. 제품 동작은 기존 0.3과 같고 검증 옵션만 추가됐다.

첫 음성 약 11초는 여전히 실시간 목표에 미달한다. 실제 카메라 질문, 사용자 발화 정확도, 음향 끼어들기/에코, 5분 대화·10회 중단, Bluetooth·발열은 이번 시험에서 합격 판정하지 않았다. Galaxy S 검증도 이 태블릿 결과로 대체하지 않는다.
