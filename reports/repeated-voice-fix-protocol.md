# 수정 후 동일 시나리오 평가 - 2026-10-14

최종 Android 0.21, SM-X926N. 기준선 `repeated-voice-results.json`은 덮어쓰지 않는다.
`repeated-voice-protocol.md`의 동일 6개 발화, 순서, 타이밍, 5회와 판정 기준을 유지한다.
최종 검증은 기본 rounds=5이며 개발/부분 시행은 별도 파일로 보존한다.

변경: 활성 타이머의 작업 종류만 ASR 시스템 문맥으로 전달한다. 인식 문자열이나 숫자를
후처리로 교정하지 않는다. 발화마다 문맥을 고정하고 취소 시 폐기한다.
VLM에는 현재 질문을 별도 사용자 메시지로 전달하고 세션 상태를 배경으로 구분한다.
최근 대화는 현재 작업 범위로 선택하며 이전 대화 자체를 삭제하지 않는다.
사진이 없는 일반 질문에 불필요한 화면 없음 문구를 앞세우지 않는다.
일반 답변 지침을 단순화하며 생성 상한은 128에서 192 token으로 늘린다.
결과 전달까지 끝난 타이머는 다음 일반 질문의 목표로 남기지 않는다.
원본 모델/업스트림 revision, 입력 문장, 시스템 오디오 장치·음량 정책은 유지한다.
단, 일반 질문 실패를 실제 비교한 뒤 VLM 파생본을 기존 QAT에서 같은 원본 revision의
기본 INT4로 교체했다. ASR/TTS/observer 파일은 동일하다. 이는 프롬프트만 바꾼
엄격 대조가 아니며, 실제 파일 해시와 CPU/기기 비교를 함께 보고한다.

샐러드는 원문을 읽어 최소 두 조리 행동, 소금 제외, 대상 적합성을 판정한다.
첫 개발안의 부적절한 볶기/끓이기와 0.19 반복 시행의 타이머 혼동은 실패로 보존한다.
정확도, 전체 전달, 지연, 실패를 함께 보고하며 사람의 마이크 정확도나 전체 Live 합격으로
일반화하지 않는다.

## 후속 사용자 음성 요구 반영

사용자가 입력 음성을 들을 수 없어 맥락을 이해하기 어렵다고 하여 모의 입력을
시스템 미디어 경로로 함께 재생한다. 동일 음색 구분 어려움, 높은 톤 불쾌감에 대한
피드백을 반영해 높은 톤 시행을 즉시 중단하고 별도 원본으로 보존했다.

최종 사용자 선택은 설치된 남성 한국어 `ko-kr-x-koc-local`을 모의 입력 합성에
우선 사용한다. 없으면 `ko-kr-x-kod-local`, 둘 다 없으면 기존 설치 음성으로
돌아간다. 음높이/속도 변조는 없으며 실제 선택 이름을 원본 결과에 기록한다.
AI 출력 음성은 기존 설정을 유지한다. 재생과 인식은 같은 모의 PCM을 사용하고,
실제 마이크는 계속 읽되 모의 모드에서는 수집한 실제 소리를 모델에 전달하지 않는다.

최종 입력 화자는 기준선과 다르다. 같은 문장/순서/5회지만 화자까지 동일한 대조는
아니다. ASR 코드 변경 자체의 동일 화자 증거는 0.19의 30/30 인식 시행을 별도로
사용하며, 최종 차이를 모두 코드 효과로 단정하지 않는다. 중단 시행은 합산하지 않는다.
