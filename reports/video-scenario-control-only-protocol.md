# 영상·음성 동시 입력 시나리오 (2026-10-14)

Android 0.22, SM-X926N. 동일 시나리오 3회, 회차마다 세션 초기화.
사전 판정 기준이며 실제 결과는 `android-video-replay-validation.md`를 따른다.

## 입력

- 영상: Big Buck Bunny 예고편의 실제 움직이는 세 구간을 각각 30초씩 반복하고,
  마지막 숲 장면을 120초 유지한 180초/640×360/24fps 무음 MP4. 원래의 연속 사건 영상이 아니다.
- 0–30초: 흰색·회색 큰 토끼, 풀밭·하늘.
- 30–60초: 나무 옆 작은 동물 세 마리.
- 60–180초: 나무와 풀밭, 나무 아래 어두운 구멍. 토끼 없음.
- 음성: 설치된 오프라인 남성 TTS → 실제 속도 PCM → Capture/Silero VAD →
  Qwen ASR → 공통 작업 메모리 → 기기 VLM/타이머 → 로컬 TTS/AudioTrack.
  입력 문장이나 정답 레이블을 인식/영상 모델에 직접 넣지 않는다.
- 영상의 원래 소리는 입력하지 않는다. 마이크 또는 모의 음성을 별도 동시 입력한다.
  실제 마이크 검사와 합성 음성 재현은 구분한다.

## 순서

1. 영상 재생 중 동물과 배경을 자세히 설명해 달라고 말한다.
2. 실제 답변 재생 중 30초 타이머를 요청한다.
3. 재생 중 10초로 변경한다.
4. 다시 20초로 변경한다.
5. 만료 1.7초 전에 영상 질문을 시작한다. 실제 발화 중 완료 결과가 도착해도 발화를 가로채지 않아야 한다.
6. 영상 답변 전달 뒤 새 질문 없이 타이머 완료를 안내해야 한다.
7. 완료 안내 중 “잠깐만”으로 보류한다. 미전달 결과는 한 개이고, 보류 중 다시 말하지 않아야 한다.
8. “계속해”로 재개한다. 완료 결과는 실제 재생 후 한 번만 전달 완료된다.
9. 장면 전환 후 현재 화면을 묻고, 선택된 원본 프레임과 답변을 비교한다.
10. 영상만 끄고 현재 동물을 묻는다. 마이크는 계속 수집하고 현재 화면을 볼 수 없다고 답해야 한다.
11. 세션을 종료하고 영상·대화 기억과 입력을 정리한다.

## 판정

- 정확한 확정 ASR 원문, 30/10/20초 실제 도구 상태, 이전 타이머 취소, 출력 중 실제
  끼어들기·늦은 PCM 거부, 입력 수집량·영상 프레임 증가를 기록한다.
- 만료 시 `userActive`와 미전달 결과가 동시에 존재해야 하며 이때 후속 안내는 없어야 한다.
  영상 답변 전달 뒤 완료 안내, 중단·보류·재안내, 중복 없음은 각각 판정한다.
- 프레임은 발화 마지막 유성 PCM 처리 시각 이전 최대 3초이며, ASR 전에 고정한다.
  재생 위치는 근사값이고, 미리보기 복사 시각은 센서 노출/정확한 디코더 PTS가 아니다.
- 실제 선택 JPEG를 git 제외 경로에 저장한다. 첫 답변은 토끼와 보이는 배경을 언급해야
  한다. 전환 뒤 답변은 선택 프레임의 사물을 설명하고 이전 토끼를 현재 대상으로
  이어 붙이지 않아야 한다. 영상 off는 현재 동물 단정을 하지 않아야 한다.
- 응답 재생 중 자르는 첫 답변은 전달된 부분/생성된 부분을 구분하고, 완료한 답변은
  최종 전문을 검토한다. 정답 키워드 하나 또는 비어 있지 않은 출력만으로 합격하지 않는다.
- 지연은 감지→AudioTrack 정지, 발화 anchor→첫 쓰기, 전체 재생 완료를 구분한다.
  실제 귀에 들린 시각, p95, 소음/에코/열/Galaxy S12GB 또는 전체 Live 합격이 아니다.
