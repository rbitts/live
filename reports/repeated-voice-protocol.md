# 고정 반복 음성 평가 계획 — 2026-10-14

결과를 보기 전에 정한 계획이다. 제품 동작·모델·프롬프트를 변경하지 않고
SM-X926N의 Android0.18에서 같은 순서를 5회 반복한다. 각 회는 세션 기억을
초기화하며 모델 프로세스는 유지한다. 단일 합성 화자의 반복성 검사다.

1. “삼십 초 타이머 시작해 줘.”
2. 시작 안내 중 “십 초 타이머로 바꿔 줘.”
3. 다음 안내 중 “이십 초 타이머로 바꿔 줘.”
4. 타이머 완료 안내 중 “잠깐만.”
5. 1.8초 보류 확인 후 “계속해.”
6. 결과 전달 완료 후 “소금은 빼고 샐러드 만드는 방법 알려 줘.”

10초 변경이 실패해도 20초 변경을 포함한 같은 순서를 계속한다. 실패 발화를
정답 텍스트로 대체하지 않는다. 각 단계의 제한 시간 초과도 결과로 남긴다.
앱 이탈/모델 로드 실패 등 평가 불가능 상태는 중단으로 보고하며 미실행 입력을
성공 또는 인식 실패로 채우지 않는다. 재시도 실행은 별도 식별한다.

입력은 매번 앱의 mock TTS→16k PCM→실제 속도 Capture/VAD→Qwen ASR다.
원문·인식 결과·응답 원문·도구 상태·출력 시작 및 실제 완료를 저장한다.

## 사전 채점 기준

- ASR 완전 일치: 띄어쓰기와 문장부호를 제거하고 Unicode NFC로 정규화한다.
  한글/아라비아 숫자 표기는 의미 기준과 분리한다. CER도 같은 정규화로 계산한다.
- ASR 의미 성공: 요청의 동사·대상·숫자·부정/제외 조건이 모두 보존된 경우다.
  10초→시초는 실패다. 정확한 원문은 보고서에 남긴다.
- 작업 실행 성공: 해당 발화 직후 실제 목표/도구 상태가 요청한 30/10/20초로
  반영돼야 한다. 명확하지 않은 입력에 대한 재확인은 안전한 처리일 수 있지만
  요청한 작업 실행 성공으로 집계하지 않는다.
- 결과 안내: 새 사용자 입력 없이 올바른20초 결과가 발화하고, 중단 후
  미전달1/완료0으로 보류하며, 재개 후 미전달0/완료1이 되고 중복이 없어야 한다.
- 일반 답변 성공: 샐러드를 만드는 실행 가능한 조리 동작을 최소2개 제시하고,
  소금 추가를 지시하지 않으며, 질문 재진술만 하거나 타이머 이야기로 답하지 않아야 한다.
  답변 원문을 직접 판독해 채점한다. 메모리에서 “소금 제외” 발견만으로 성공 처리하지 않는다.
- 음성 전달: 의도적 끼어들기 외의 최종 답변은 전체 PCM 쓰기와 재생 head 도달을 확인한다.

분모는 항목별로 밝힌다: 발화30개, 타이머 명령15개, 결과 안내5회, 일반 답변5개.
5개의 동일 합성 발화는 독립 화자 표본이 아니므로 전체 사용자 정확도나 확률 보장으로
일반화하지 않는다. 정상 완료율과 과업/답변 품질 성공률을 따로 보고한다.

첫 write 지연은 앱 응답 시작 기준이며 실제 들린 순간·완전한 발화 종료 기준과
다르다. send-to-onset에는 합성/선행 무음이 포함된다. 일반 답변5개의 지연은
개별 값과 중앙값·최댓값 위주로 보고하고 제품 p95 보장으로 취급하지 않는다.
